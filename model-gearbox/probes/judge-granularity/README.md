# judge-granularity — P1 核验能力探针

**测什么**：模型的核验能力档位——能以什么形态当核验官（D12 实践维度 P1;考的是核验框架的自我管理,与推理正确性分测不许互推）。产出=档案 `dims.check_judge` 的档位值：`open-ok | checklist-only | closed-questions-only | unusable`。

## 三层阶梯（从重到轻，逐层定坍塌点）

每层都用**同一对固定语料**（好卷/坏卷双臂——判分基准是已知的，模型判定对不对机械可核）：

| 层 | 判定形态 | 模型要额外扛的协调负担 | 指标 |
|---|---|---|---|
| L1 开放式核验 | 整份产出+判据散文，模型自建核对框架 | 建框架+遍历+汇总+跨轮框架一致 | **自反率**（同一对象多轮判词出现相反指令）；判词跨轮标准漂移 |
| L2 按清单核验 | 封闭问题清单（Q1-Q6）+禁裁量条款+机械汇总规则，逐题作答 | 多题间自洽（逐题答案与终判一致） | 好卷**误杀率**；坏卷**检出率**；**表内矛盾率**（Q 行答案与 extract_ok 汇总不一致）；**定位准确率**（gap 是否点名真病灶） |
| L3 单点核验 | 一次调用一个 yes/no（一行一断言一问） | 无——只剩原子判断 | 正确率；漏项定位准确率 |

## 语料（corpus/）

- `points-good.yaml` — 好卷：S 档语料的 5 点提取（strong 模型判 true 的同一份，作独立基准）；
- `points-bad.yaml` — 坏卷：好卷删去 FDA 点（P4）——真严重漏项，L3 整行断言无人认领；
- 文档原文=`../extract-scaling/doc-s.md`（两族共用，改一处两处同步）。

三层的 prompt 模板见 `templates.md`。**语料与模板是判分基准的一部分**——改一字即换了考卷，跨模型对比必须同卷。

## 判档规则（机械）

- L1 自反率 > 0（n≥3 轮内出现相反指令）→ 排除 `open-ok`；
- L2 好卷误杀 ≤1/6 且坏卷检出 ≥5/6 且定位准确 ≥4/6 → `checklist-only`；定位准确 <4/6（判向对定位废）→ 继续 L3；
- L3 正确率=100%（好坏双臂各 n≥6）→ `closed-questions-only`；L3 也不稳 → `unusable`。

## 跑法（现阶段手工，脚本化挂 0095 run-probes 批）

直连被测端点（`curl`/python urllib，参照 extract-scaling 跑批纪律：模型身份取响应体 model 字段、每格 n≥6、好坏双臂都跑）。每层判据机械可核：自反=两轮判词对同一点给出相反改法（人工比对，n 小可承受）；误杀/检出/定位=对已知基准机械比对。

## 首批实测（Qwen3.8-27B 百炼，2026-09-18）

| 层 | 结果 | 形态 |
|---|---|---|
| L1 开放式核验 | **自反实锤** | 三轮三标准；判词1令 P3 改 fact→执行者照办→判词3令改回 inference |
| L2 按清单核验 | 判向可用，定位废 | 好卷 6/6 判真（裁量摇摆消失）；坏卷 11/12 判假；**表内矛盾**（Q 行答 yes 终判按 no 算）+语义边界塌（premises 提及被当覆盖），定位 0/6 |
| L3 单点核验 | **6/6 全对** | 含漏项精确定位（"missing: ②"） |

→ 定档 `closed-questions-only`。适配落地=check 步微判定展开（范本 `examples/hop-fact-check.qwen3.8-27b.md`，引擎真机串行/并发双过关）。deepseek-flash/Ling 未按本阶梯跑（档案标 untested）。
