# P1 三层探针 prompt 模板

判分基准的一部分——改一字即换考卷，跨模型对比必须同卷。占位符：`{DOC}`=带行号文档全文（corpus 同源 `../extract-scaling/doc-s.md` 逐行加 `L<n>: ` 前缀）；`{POINTS}`=corpus/points-good.yaml 或 points-bad.yaml 的条目体。

## L1 开放式核验（测自反——同臂连发 n≥3 轮，逐轮比对判词是否互相矛盾）

```
你是提取完备性验收员。下面是文档全文（带行号）和从中提取的核查点清单。
逐段扫文档，核对清单是否穷尽——是否有可查证断言未列为 fact、有结论未列为 inference、有断言被误分类、推演点前提缺失。
只有严重问题才打回（漏了断言/分类错到核查路径走错/前提缺到没法核查），一次列全；拆分方式等裁量偏好不是打回理由。

## 文档全文
{DOC}

## 核查点清单
{POINTS}

## 交付格式（直接输出 YAML，不要围栏）
extract_ok: true/false
extract_gap: |
  （false 时逐条列出）
```

## L2 按清单核验（测多题自洽——好/坏双臂各 n≥6）

```
你是完备性核对员。下面是文档全文（带行号）和从中提取的核查点清单。你的工作是按核对表逐项回答封闭问题，然后机械汇总。

## 文档全文
{DOC}

## 提取的核查点清单
{POINTS}

## 核对表（逐项回答,每项只答 yes/no + 一句话依据）

按行核对覆盖。**"有对应点"的定义（严格按此判）**：清单里存在一个点,它的 line_ref 就是该行、quote 摘自该行。**别的点在 premises 里提到该行内容不算对应点**——premises 是前提引用,不是提取覆盖;该行断言没有自己的点=漏提。
- Q1: L1 的断言,清单里有对应点吗?
- Q2: L2 的断言（半衰期+影响睡眠,两个内容;都被 line_ref=L2 的点覆盖才算 yes）,清单里有对应点吗?
- Q3: L3 的断言,清单里有对应点吗?
- Q4: L4 的断言,清单里有对应点吗?

按点核对可用性（只判"能不能用",不判"是不是最优拆法"）：
- Q5: 每个 inference 点的 premises 都非空且写了内容（不是只写编号）吗?
- Q6: 每个点的 quote 都能在原文对应行里找到吗?（都能找到=yes）

## 严格禁止
- 禁止评价拆分方式（合成一点还是拆成两点都合法,不是你的工作）;
- 禁止评价 fact/inference 分类是否最优（只要不是明显荒谬,放行）;
- 禁止提出核对表之外的新要求。

## 汇总规则（机械）
Q1-Q6 全部 yes → extract_ok: true,extract_gap 置空;任何一项 no → extract_ok: false,extract_gap 只写 no 的那几项（引用 Q 编号+缺什么）。

## 交付格式（直接输出 YAML,不要围栏）
Q1: yes/no（依据一句话）
Q2: yes/no（依据一句话）
Q3: yes/no（依据一句话）
Q4: yes/no（依据一句话）
Q5: yes/no（依据一句话）
Q6: yes/no（依据一句话）
extract_ok: true/false
extract_gap: |
  （只在 false 时写,引用 Q 编号）
```

判分：`extract_ok` 对基准判误杀/检出；**表内矛盾**=任一 Q 行答案与汇总规则推出的 extract_ok 不一致；**定位**=gap 是否点名真病灶所在 Q（坏卷=Q3）。

## L3 单点核验（测原子判断——按行×断言逐题，好/坏双臂各 n≥6）

```
只回答一个封闭问题。

原文行: "{LINE_TEXT}"
这一行含 {N} 个断言: {ASSERTION_LIST}

清单里 line_ref={LINE_ID} 的点:
{LINE_CLAIMS}

问题: 每个断言是否都各有至少一个点覆盖其内容（claim 提到该断言即算覆盖,不论 fact/inference 分类）?
输出恰两行:
covered: yes/no
missing: （no 时写漏了第几个断言;yes 时留空）
```

判分：covered 对基准；missing 定位对基准（坏卷 L3 行期望 no+FDA 断言）。
