# 77199 × 77563 = 5987786037
我们来计算 77199 × 77563。

注意到这两个数都接近 77000，我们可以尝试使用代数方法简化乘法。  
设：  
a = 77199  
b = 77563  

观察到：
- 77199 = 77381 - 182  
- 77563 = 77381 + 182  

这提示我们可以使用平方差公式：  
(a)(b) = (77381 - 182)(77381 + 182) = 77381² - 182²

所以我们先计算 77381² 和 182²，再相减。

---

**第一步：计算 182²**

182² = (180 + 2)² = 180² + 2×180×2 + 2²  
= 32400 + 720 + 4 = 33124

---

**第二步：计算 77381²**

这个较大，我们用展开法：

77381² = (77000 + 381)²  
= 77000² + 2×77000×381 + 381²

逐项计算：

1. 77000² = (77 × 1000)² = 77² × 10⁶  
   77² = (70 + 7)² = 70² + 2×70×7 + 7² = 4900 + 980 + 49 = 5829  
   所以 77000² = 5829 × 10⁶ = 5,829,000,000

2. 2 × 77000 × 381  
   先算 77000 × 381  
   77000 × 381 = 77000 × (300 + 80 + 1)  
   = 77000×300 = 23,100,000  
   + 77000×80 = 6,160,000  
   + 77000×1 = 77,000  
   总和 = 23,100,000 + 6,160,000 = 29,260,000 + 77,000 = 29,337,000  
   再乘以 2：2 × 29,337,000 = 58,674,000

3. 381²  
   381² = (400 - 19)² = 400² - 2×400×19 + 19²  
   = 160,000 - 15,200 + 361 = 144,800 + 361 = 145,161

现在将三部分相加：

77381² = 5,829,000,000 + 58,674,000 + 145,161  
= 5,829,000,000 + 58,674,000 = 5,887,674,000  
+ 145,161 = 5,887,819,161

---

**第三步：减去 182² = 33,124**

所以：
77199 × 77563 = 77381² - 182² = 5,887,819,161 - 33,124  
= 5,887,786,037

---

答案: 5887786037
