# 4942 × 8870 = 43835540
我们来计算 4942 × 8870。

我们可以将 8870 拆分为 8000 + 800 + 70，然后分别计算乘积再相加。

先算：

1. 4942 × 8000  
   = 4942 × 8 × 1000  
   先算 4942 × 8：  
   4000×8 = 32,000  
   900×8 = 7,200 → 32,000 + 7,200 = 39,200  
   40×8 = 320 → 39,200 + 320 = 39,520  
   2×8 = 16 → 39,520 + 16 = 39,536  
   所以 4942 × 8 = 39,536  
   再 ×1000 → 39,536,000

2. 4942 × 800  
   = 4942 × 8 × 100  
   已知 4942 × 8 = 39,536  
   ×100 → 3,953,600

3. 4942 × 70  
   = 4942 × 7 × 10  
   先算 4942 × 7：  
   4000×7 = 28,000  
   900×7 = 6,300 → 28,000 + 6,300 = 34,300  
   40×7 = 280 → 34,300 + 280 = 34,580  
   2×7 = 14 → 34,580 + 14 = 34,594  
   然后 ×10 → 345,940

现在把三部分相加：

- 39,536,000  
- + 3,953,600 → 39,536,000 + 3,953,600 = 43,489,600  
- + 345,940 → 43,489,600 + 345,940 = 43,835,540

答案: 43835540
