# 5342 × 8862 = 47340804
我们来计算 5342 × 8862，使用纯推理的乘法方法。

我们可以将 8862 拆分为：  
8000 + 800 + 60 + 2

然后分别计算：

1. 5342 × 8000  
   = 5342 × 8 × 1000  
   先算 5342 × 8：  
   5000×8 = 40,000  
   300×8 = 2,400  
   40×8 = 320  
   2×8 = 16  
   相加：40,000 + 2,400 = 42,400  
   42,400 + 320 = 42,720  
   42,720 + 16 = 42,736  
   所以 5342 × 8 = 42,736  
   再 ×1000 → 42,736,000

2. 5342 × 800  
   = 5342 × 8 × 100  
   我们已有 5342 × 8 = 42,736  
   ×100 → 4,273,600

3. 5342 × 60  
   = 5342 × 6 × 10  
   先算 5342 × 6：  
   5000×6 = 30,000  
   300×6 = 1,800  
   40×6 = 240  
   2×6 = 12  
   相加：30,000 + 1,800 = 31,800  
   31,800 + 240 = 32,040  
   32,040 + 12 = 32,052  
   ×10 → 320,520

4. 5342 × 2 = 10,684

现在把所有部分相加：

- 42,736,000  
- + 4,273,600 → 47,009,600  
- + 320,520 → 47,330,120  
- + 10,684 → 47,340,804

逐步核对加法：

42,736,000  
+ 4,273,600  
= 47,009,600 ✅

47,009,600  
+ 320,520  
= 47,330,120 ✅

47,330,120  
+ 10,684  
= 47,340,804 ✅

所以最终结果是 47,340,804。

答案: 47340804
