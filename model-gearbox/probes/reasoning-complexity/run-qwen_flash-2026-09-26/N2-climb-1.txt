# 66 × 68 = 4488
我们可以使用分配律来计算 66 × 68。

注意到 66 和 68 都接近 67，但更方便的是利用“平方差”公式：  
如果两个数的平均值是整数，可以表示为 (a - b)(a + b) = a² - b²。

这里，66 和 68 的平均数是 67，它们分别比 67 少 1 和多 1。  
所以：

66 × 68 = (67 - 1)(67 + 1) = 67² - 1²

现在计算 67²：

67² = (60 + 7)² = 60² + 2×60×7 + 7² = 3600 + 840 + 49 = 4489

然后减去 1²（即 1）：

4489 - 1 = 4488

答案: 4488
