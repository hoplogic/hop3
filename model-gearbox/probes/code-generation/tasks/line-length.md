# line-length — 每行不超过 100 个字符（Python · 简单）

> 发给模型的是下面「题目正文」一节的原文；跑批脚本 `../run-code-generation.mjs` 再给它套上固定外框，并在末尾附上 `public/` 下的公开样例。这段说明不发给模型。

## 题目正文

规范条款:文本文件里每一行的长度不得超过 100 个字符。
规则细节:
- 长度按字符数算,不按字节数算(一个汉字算 1 个字符);
- 行尾的换行符不计入长度,Windows 换行(`\r\n`)里的 `\r` 也不计入;
- 文件最后一行没有换行符结尾时,这一行同样要检查;
- 恰好 100 个字符是合规的,101 个字符才违规;空文件合规。
