# func-length — 函数不超过 40 行（Python · 普通）

> 发给模型的是下面「题目正文」一节的原文；跑批脚本 `../run-code-generation.mjs` 再给它套上固定外框，并在末尾附上 `public/` 下的公开样例。这段说明不发给模型。

## 题目正文

规范条款:Python 源文件里每个函数的长度不得超过 40 行。
规则细节:
- 函数长度 = 从 def 所在行到函数体最后一行的行数(含首尾两行);装饰器行不计入;
- 普通函数、async 函数、类里的方法都要检查;
- 嵌套函数各自单独计算:外层函数的长度包含内层函数所占的行,内层函数也单独检查;
- 恰好 40 行合规,41 行违规;模块顶层的普通语句不属于任何函数,不检查。
