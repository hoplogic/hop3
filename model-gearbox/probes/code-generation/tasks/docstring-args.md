# docstring-args — 公开函数必须有文档字符串且提到每个参数（Python · 复杂）

> 发给模型的是下面「题目正文」一节的原文；跑批脚本 `../run-code-generation.mjs` 再给它套上固定外框，并在末尾附上 `public/` 下的公开样例。这段说明不发给模型。

## 题目正文

规范条款:Python 源文件里每个公开函数都必须有文档字符串,并且文档字符串里要提到它的每一个参数。
规则细节:
- 要检查的函数:模块顶层的函数(普通函数与 async 函数),以及类里的方法(包括类里嵌套的类的方法);
  函数名以下划线开头的不检查(包括 `__init__`、`__repr__` 这类双下划线方法);
  定义在函数体内部的函数和类(嵌套函数、局部类的方法)不检查;
- 文档字符串 = 函数体的第一条语句是一个字符串字面量;函数体里后面才出现的字符串不算文档字符串;
- 参数包括:仅位置参数(`/` 之前的)、普通参数、`*args` 形式的参数、`*` 之后的仅关键字参数、`**kwargs` 形式的参数;
  其中名叫 self 或 cls 的参数不要求提到;
- "提到"= 参数名作为一个完整的词出现在文档字符串里(大小写敏感):参数 count 在文本 "recounting" 或 "counter"
  里不算提到;在 "count."、"`count`"、"(count)" 里算提到;
- 函数没有文档字符串,或文档字符串漏掉了任何一个要求提到的参数,都算违规;空文件合规。
