思路说明(对应规范细节):

- 用 `open(path, 'r', encoding='utf-8')` 以 UTF-8 文本模式读取，长度即 Python 字符串长度(按码点计，一个汉字算 1 个字符)；
- 先把 `\r\n` 统一替换成 `\n` 再按 `\n` 切行(文本模式通常已做换行转换，这里再兜底一次)，保证 `\r` 不计入行长度；
- 切行后如果末尾是空串，说明文件以换行结尾，这个空串不是真实的一行，丢弃；如果最后一行没有换行符结尾，切出来的就是它本身，照样检查；
- 判定条件是 `len > 100`(恰好 100 合规，101 违规)；空文件切行后丢弃末尾空串得到空列表，自然合规，退出 0;
- 有违规时逐行打印「行号 + 原因(实际长度与上限)」，退出 1;参数缺失、文件打不开或不是合法 UTF-8 时打印错误到 `sys.stderr` 并以 2 退出(区别于「违规」的 1)。

```python
import sys

# 用法检查
if len(sys.argv) < 2:
    print("用法: python check_line_length.py <文件路径>", file=sys.stderr)
    sys.exit(2)

path = sys.argv[1]

# 以 UTF-8 文本模式读取整个文件
try:
    fh = open(path, 'r', encoding='utf-8')
    content = fh.read()
    fh.close()
except OSError:
    print("错误: 无法读取文件 " + repr(path), file=sys.stderr)
    sys.exit(2)
except ValueError:
    print("错误: 文件不是有效的 UTF-8 编码 " + repr(path), file=sys.stderr)
    sys.exit(2)

# 统一换行符: Windows 换行 \r\n 中的 \r 不计入行长度
# (文本模式通常已把 \r\n 转成 \n, 这里再兜底一次)
content = content.replace('\r\n', '\n')

# 按 \n 切行; 若文件以换行结尾, 切分后末尾会多出一个空串, 它不是真实的一行, 丢弃
lines = content.split('\n')
if len(lines) > 0 and lines[-1] == '':
    lines.pop()

# 逐行检查: 长度按字符数计, 恰好 100 合规, 101 起违规
# 空文件时 lines 为空列表, 循环不执行, 自然合规
has_violation = False
for idx in range(len(lines)):
    line_text = lines[idx]
    line_len = len(line_text)
    if line_len > 100:
        has_violation = True
        print("第 " + str(idx + 1) + " 行超长: 长度 " + str(line_len) + " 个字符, 超过上限 100")

if has_violation:
    sys.exit(1)
sys.exit(0)
```
