# 月度供应商对账审计

每月对全部供应商执行对账审计，产出审计报告并把确认无误的付款单提交财务系统。

## 流程

### 第一阶段：逐供应商对账

对供应商清单里的每个供应商：

1. 拉取该供应商本月的全部发票和我方采购订单；
2. 对该供应商的每张发票，逐张核对：发票金额与对应采购订单金额是否一致、收货记录是否在场、税率计算是否正确。三项核对都要留下核对结论；
3. 金额不一致的发票不要硬轧平——把差异金额和原因分析记入差异清单，连同核对结论一起进报告；
4. 该供应商全部发票核对完后，汇总出该供应商的对账小结（总金额、一致张数、差异张数、差异清单）。

### 第二阶段：汇总与分级

全部供应商对账完成后：

1. 汇总所有供应商的对账小结，生成月度对账总表；
2. 按差异严重度给每个供应商分级：零差异的标"清"，差异金额低于总额 1% 的标"轻微"，超过 1% 的标"重大"；
3. "重大"级供应商必须逐个写出差异根因分析，不许只给一个数字。

### 第三阶段：审批与提交

1. 把月度对账总表和全部"重大"级根因分析呈给财务主管审批——主管必须看到完整差异清单才能拍板，不许只给摘要；
2. 主管批准后，对每个"清"级供应商的付款单，逐单提交到财务系统。提交是不可逆操作，提交前必须再核一遍该单金额与对账小结一致；
3. 有任何一单提交失败，停止后续提交，把已提交清单和失败原因整理上报。

约束：每个供应商、每张发票都必须核到，不得遗漏；差异如实报告，不许为了平账修改数字；付款单提交前必须经过主管批准。
